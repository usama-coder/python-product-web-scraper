# python-product-web-scraper
Built a Python web scraping tool that extracts structured product information from a demo e-commerce website and exports the collected data into a clean Excel file.

The scraper collects product title, price, availability, and rating using Requests and BeautifulSoup. Pandas and OpenPyXL are used to organize and export the extracted data into Excel format.

This project demonstrates my ability to build data extraction tools for product research, competitor analysis, price monitoring, lead generation, and general web data collection tasks.
